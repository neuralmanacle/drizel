# Step 3 — Window shapes and interpolation

**Date:** 2026-10-12  
**Commit:** [`289bc0e`](https://github.com/neuralmanacle/drizel/commit/289bc0e9841e1bb7c2174b8e94e2198ffc569370)

Added the first DSP building blocks for Drizel's future grain player.

## Changes

- `Window.h`: precomputed symmetric Hann envelopes to fade grains in and out, reducing abrupt edge discontinuities. Tables are prepared outside audio processing.
- `Interpolation.h`: allocation-free linear interpolation for fractional source positions. Samples beyond the source are zero-padded, including fractional blends at the edges.
- Added documentation, Projucer entries, and a CTest target for the primitives.
- Added the missing offline WAV round-trip experiment source.

## Validation

All ten primitive test cases passed, covering window values and symmetry, overlap conventions, fractional reads, source boundaries, invalid positions, stereo separation, and traversal.

## Takeaway

Windowing controls a grain's amplitude over time. Interpolation estimates values between stored samples. Pitch changes come from the playback increment and remain optional; linear interpolation alone does not adequately prevent resampling aliasing.

## Next

Connect these primitives in a grain voice with its own age and source position. Alternative windows, higher-order interpolation, scheduling, and listening comparisons remain future work.
