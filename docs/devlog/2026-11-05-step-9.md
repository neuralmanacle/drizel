# Step 9 — MIDI instrument, presets and packaging

Combines roadmap Layers 7 and 8. Drizel now has a channel-1 monophonic MIDI
mode alongside its existing Drone mode. Notes select pitch relative to an
adjustable root, velocity drives an attack/release envelope, and last-note
priority returns to older held notes. Bend, mod wheel, position/density CCs,
controller reset and panic messages are handled at their sample offsets.

The note/controller state is a fixed-size framework-independent class. The
callback reads borrowed MIDI bytes, applies MIDI pitch through the existing
smoother, and applies the amplitude envelope after engine gain smoothing.
The same shared grain cloud remains active underneath the gate. Existing grain
pitch is retained until each grain ends, so note changes blend across the cloud.

The editor adds mode, attack, release, root note and preset controls. Presets
use the existing host-state format and reference the WAV by absolute path.
Performance state and sample data are not embedded; exact waveform replay is
not promised. Preset/host restore clears held notes on the next audio block.

Both build descriptions enable MIDI input. macOS CI is configured to build
Standalone/VST3/AU, run the processor tests and upload unsigned development
artifacts. That configuration is not a claim that macOS CI or host validation
has already passed.
