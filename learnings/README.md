# Learning Path

This directory contains the theory and implementation notes required to
develop the custom granular synthesis engine.

## Learning order

1. C++ programming
2. Mathematics for audio
3. Digital audio representation
4. Sampling and interpolation
5. Envelopes and window functions
6. Resampling and pitch
7. Modulation
8. Grain scheduling
9. Real-time audio
10. Filters and spectral analysis
11. MIDI and plugin development

## Rule

Each topic should produce a small experiment in `experiments/` and,
when stable, a reusable implementation in `src/`.
